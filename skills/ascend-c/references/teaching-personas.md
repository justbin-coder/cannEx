# 教学画像参考

来源：CannEx PRD §3。问题驱动画像——用真实问题定义层级，问题本身就是能力信号。

---

## Beginner — "连问题空间都还没看清"

**典型身份**：
- AI 算法工程师（熟悉 PyTorch，日常 `model.forward()` 就能跑）
- 科班 C++ 开发者（从未接触 GPU/NPU 编程）
- 高校研究生（导师要求"把模型跑在昇腾上"）

**典型问题与认知缺口**：

| 问题 | 认知缺口 | 应答策略 |
|---|---|---|
| "算子开发是干什么的？PyTorch 不够吗？" | 不理解算子在部署链路的位置 | 画全景：模型→框架→算子→硬件 |
| "Ascend C 和 CUDA 什么关系？要先学 CUDA 吗？" | 不确定学习路径依赖 | 明确"不需要"，用 CUDA 做类比桥梁 |
| "算子有多少种？先学哪种？" | 缺分类全景 | 给四类分类图，明确从纯 Vector 开始 |
| "TPipe、TQue 是什么？" | 不理解异构编程的数据搬运本质 | 厨房比喻：冰箱(GM)→案板(UB)→炒锅(计算)→盘子(GM) |
| "编译过了但结果不对，怎么调试？" | 不知道调试工具 | CPU 模式对比、printf、数据 dump |
| "什么是 Tiling？数据量小也要吗？" | 不理解硬件缓存容量约束 | 从 UB 大小出发：放不下就要分块 |

**核心恐惧**：
- "文档 700 页，从哪开始？"
- "代码能编译但结果不对，完全不知道怎么调试"
- "CUDA 我也不会，是不是要先学 CUDA？"

**应答原则**：先 Why（为什么需要算子开发），再 What（算子分类），最后 How（怎么写）。
严格控制信息量——**一次只教一个概念**。

## Intermediate — "我能跑通，但不知道怎么跑好"

**典型身份**：
- 已写过 1-3 个 Vector 算子，通过编译和正确性验证
- 开始接触 Cube 算子或被要求优化性能
- 参与团队项目，需要写"能上线"的算子

**典型问题**：

| 问题 | 认知缺口 | 应答策略 |
|---|---|---|
| "Double Buffer 开了但没提速" | 不会分析流水瓶颈 | 教流水时序分析：画时间轴，判断瓶颈在 Compute 还是 CopyIn |
| "UB 256KB，3 个 tensor 怎么分？" | 不会做 UB 内存规划 | 教内存规划公式：对齐(32B) × Double Buffer(×2) × 预留 |
| "LayerNorm 融合的中间变量怎么处理？" | 不会设计 Vector 融合数据流 | 教 VECCALC 临时空间使用，画融合数据流图 |
| "Matmul 的 Tiling 参数怎么算？" | 不理解多维 Tiling 约束 | 从 L1/L0 容量反推，给计算模板 |
| "Atlas A2 能跑但 Atlas 300 报错" | 不理解跨平台差异 | 引导检查 UB 大小、数据类型支持、指令集差异 |

**应答原则**：从"你的算子为什么慢"开始，用性能数据驱动学习动机。
教**性能分析心智模型**：计算 bound vs 搬运 bound → 对症优化。

## Expert — "我要逼近硬件理论峰值"

**典型身份**：
- 能独立完成各类算子开发，包括融合算子
- 追求硬件利用率 80%+，或解决极端性能需求
- 算子库团队核心开发者，或 CUDA 迁移过来的高性能计算工程师

**典型问题**：

| 问题 | 应答策略 |
|---|---|
| "有先 Cube 再 Vector 的例子？" | 给 MatMul+LeakyReLU 完整示例，重点讲 CO2→VECIN 衔接 |
| "静态 Tensor 比 TPipe 能快多少？" | 给对比数据，明确"kernel 占总时间 >30% 时值得切" |
| "L0A Bank 冲突怎么判断？" | 给微架构 Bank 分布 + 判断方法 |
| "CANN 9.0 的 DataCopy 和 8.0 行为差异？" | 跨版本兼容分析 |
| "GQA Attention 利用率卡在 70%，瓶颈在哪？" | 引导 msprof 工具 + Cube/Vector 利用率分析 |

**应答原则**：**不需要引导式教学**，按需精准查询 + 深度讨论即可。
省略基础铺垫。

## 跨层级毕业标准

| 晋级 | 标准 |
|---|---|
| Beginner → Intermediate | 独立完成一个 Vector 融合算子（如 LeakyReLU），通过正确性验证，能解释 Pipeline 三阶段 |
| Intermediate → Expert | 独立完成一个 Cube+Vector 融合算子，UB 内存规划有据可查，性能达基线 60%+ |
